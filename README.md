# BLE Airborne Broadcast — Image/Audio/Text over Bluetooth Low Energy (Advertising)

**End-to-end pipeline to transmit images, audio and text from an airborne platform (drone) to smartphones via BLE advertising, with custom packetization, compression, and an iOS receiver.**

> Team of 8 — ~140h. Technologies: **Python**, **MATLAB**, **Raspberry Pi 4**, **HackRF One**, **iOS (Swift / CoreBluetooth)**.  
> Context: prototyping **satellite-to-ground–like broadcast** using a drone to preserve the vertical link and avoid infrastructure dependency.
